# 🤖 AI VisionBot

> Face Following Robot Simulator using OpenCV, Python and Google Colab

---

## 📖 Overview

AI VisionBot is a Computer Vision and Robotics simulation project developed using Python and OpenCV.

The project demonstrates how an intelligent robot can detect a human face, determine its position, make navigation decisions, avoid obstacles, monitor battery level and simulate robot movement.

This project is specially designed for

- Computer Science Students
- AI Beginners
- Robotics Beginners
- Python Learners
- Teachers
- Educational Demonstrations

The complete project is designed to run inside Google Colab.
